## Entry Template

Copy this template for new entries:
```
**HH:MM** - action | description
```

Where:
- `HH:MM` = 24-hour time format
- `action` = one word: init, save, update, delete, research, ingest, etc.
- `description` = brief description of what happened

---

## Common Action Types

| Action | Use for |
|---|---|
| `init` | Vault initialization, first setup |
| `save` | Saving conversation or note |
| `update` | Updating existing note |
| `create` | Creating new note |
| `delete` | Deleting or archiving note |
| `research` | Research command executed |
| `ingest` | Source ingested into vault |
| `synthesize` | Synthesis or connection made |
| `decide` | Decision recorded |
| `review` | Review generated |
